## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone repository
git clone https://github.com/daniyalsaqib/daniyal-portfolio.git
cd daniyal-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Create production bundle
npm run build

# Preview production bundle locally
npm run preview
```
