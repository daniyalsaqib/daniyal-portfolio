## 💻 Portfolio Web App Architecture

This repository contains the source code for [daniyalsaqib.me](https://daniyalsaqib.me), engineered for maximum responsiveness, visual elegance, and performance.

- **Framework**: React 18 with TypeScript & Vite
- **Styling**: Tailwind CSS with custom HSL noir & gold design tokens
- **Typography**: Google Fonts (`Space Grotesk` display + `DM Sans` body)
- **Icons**: Lucide React
- **Deployment**: Vercel (Edge Network CI/CD)

### Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/daniyalsaqib/daniyal-portfolio.git
cd daniyal-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build
npm run preview
```
